# 载物台 · 植物纤维形态实验台

单文件原型：`fiber-stage.html`（直接双击打开，无外部依赖，材质已内嵌为 base64）。
数据全部为编造的示例数据，页面上盖有「示例数据」章。

## 隐喻

整个界面是一台倒置的虚拟显微镜。纤维分析仪（FQA、Kajaani）本来就是在流通池里拍纤维影像，
所以让"纤维本体"直接成为图表，而不是把它折算成柱状图，是最短的翻译路径：

* 4× 群体：每个样品 320 根模拟纤维按长度降序从顶部悬挂轨垂下，下缘轮廓就是长度分布的分位曲线，左侧测微尺直接读 mm。
* 10× 分级：Bauer-McNett 式五个筛分托盘（R14/R28/R48/R100/P100），纤维按长度飞入各自托盘，托盘宽度与级别成比例，数字为长度加权占比。点托盘即设置长度门。
* 40× 单纤：各样品门内中位纤维 1:1 宽度横放，100 µm 标尺，卷曲和纤维化（表面粗糙度）随 °SR 上升。
* 调焦旋钮 = PFI 打浆转数（0–6000）。转动它，纤维缩短、细小纤维出现、表面变毛，右侧读数与记录纸同步移动。
* 长度门：4× 下拖动红色三角，所有形态指标（Lw、Ln、宽度、卷曲、留着率、门内 n）即时按门内纤维重算；门外纤维变灰影而不消失。

## 3D 约束

* WebGL2 自写着色器，不依赖库；每根纤维是一条实例化条带，位置、角度、长度、可见度由 JS 逐帧插值后上传。
* 打浆度 → 顶点级边缘毛刺 + 片元级表面噪声；长度分布 → 悬挂梳；筛选 → 纤维重排与灰影。没有纯装饰粒子。
* 首屏先用 2D canvas 同步画出同一布局，再在下一帧接入 WebGL；无 WebGL 时保留 2D 视图并提示。
* `prefers-reduced-motion`：取消过渡飞行与闲置摆动，所有变化瞬时落位；页眉有手动开关。

## 可以砍掉而不损失信息的效果

依次为：闲置摆动（uMotion）；条带厚度与四层 z 深度（LAYERS=1）；40× 的细胞腔暗线与表面噪声；视场拖动微转；两张材质层；换物镜时的飞行过渡（直接 snap）。砍完以后仍然是悬挂梳 + 托盘 + 单纤 + 读数，数值与筛选完全不变。
